# Known robots live on the server

## Status

Accepted

A fair laptop can open the app in several windows. Known robots therefore live
with the server's data, identified by successfully connected address and the name
reported there. Keeping the list in browser storage would give each browser its
own account of which robots were available. Selecting/removing a suggestion is
separate from connecting/disconnecting; current list and field behavior is in
[behavior](../behavior.md#connection-conversation-and-transcript).
