# Next line, repeat line, and previous line use the one active dialog

A dialog action could have named the dialog it moves. That lets two gestures advance two scripts, and it asks the operator to pick a dialog on every gesture.

Next line, repeat line, and previous line do not name a dialog. The interaction mappings have at most one active dialog, chosen on the dialogs surface, and every dialog action uses that one. The same surface creates and edits the other dialogs. With no active dialog, those actions do nothing.
